# SECURITY · 安全边界

本仓库模块会**执行命令、kill 进程、启动服务**。默认配置为"只读自检"，危险能力需显式开启。

## 硬性规则

1. **凭据不进仓库**：任何私钥/token/密码文件由 `.gitignore` 排除；面值卡与账本不含凭据。
2. **白名单优先**：免疫/网关的 kill 与 exec 必须先过白名单；系统进程与用户 app 禁杀。
3. **外部暴露默认关闭**：所有本地服务默认绑定 127.0.0.1；LAN 监听必须带一次性 token 且显式开启。
4. **危险动作外签**：安装/卸载/删除/花钱/改系统设置/改核心 → 必须人工批准（本仓库提供 hook 点，不内置自动批准）。
5. **同层监控悖论**：免疫必须在**另一台机器**上运行；同机自愈只能作为最后兜底，不能作为安全保证。
6. **AI 生成内容合规**：用本架构产出图片/视频/文本时，须遵守所在司法辖区的 AI 内容标识规定（如中国《人工智能生成合成内容标识办法》2025-09-01 施行）。

## 威胁模型（不假装安全）

- 免疫进程被攻破 → 可执行任意 adb/ssh 命令：请用最小权限账号与密钥隔离。
- 网关拦截的文件不可信：面值卡只证明"未被篡改"，不证明"内容安全"。
- 词元网络可能泄露文件名结构：对外发布索引前请做脱敏（本仓库不提供脱敏器）。
