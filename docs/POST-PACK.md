# 发布物料包（今晚/明天发帖弹药）

## 0. 一句话（所有平台统一开口）
> 我们把智能体的"身体"做成了文件系统图论：零 Token 本地寻址 + 算力当量防炸 + 文件货币化 + 跨设备外部双生免疫。代码 MIT，跑在真机上，报告是真的数字。

## 1. GitHub Release（v0.1-prototype）

**标题**：NexusCore v0.1 — a graph-theoretic, compute-equivalent agent architecture

**正文**：
- 文件系统即身体：状态写在文件名上，`ls` 是查询接口，`mv` 是状态转换
- 零 Token 寻址：文件名切成词元 → PPMI 共现 → 64 维嵌入；"五公理 体检" 直接命中真实文件
- 算力当量防炸：Area = 系数×容量；实测 7.28GB 物理 / 314.52GB当量（43.22×）；>阈值强制流式，539 块 sha 校验
- 文件货币化：应用=黑盒（inputs/outputs），网关拦截输出货币 → 面值卡（面积+熵密度+sha）→ 账本 → 防篡改验证
- 外部双生免疫：免疫跑在另一台常开主机，无线 adb 探活 + 心跳/端口双判据 + 除颤脚本；四类真实 bug 已记录
- 诚实边界：面积是算力当量，**不是**信息熵（附压缩率实测对照表）

## 2. V2EX / 知乎 / 掘金 长文版

**标题**：《我让智能体住在文件系统里：零 Token 寻址、算力当量防炸、跨设备双生免疫》

结构：
1. 引子：为什么不用向量库（记忆=文件系统+名字寻址）
2. 零 Token 寻址：文件名就是词表（112,231 条名序列 → 15,188 词元 → 64 维；实测命中）
3. 算力当量：`Area = 系数×字节`（108,386 文件 → 314.52GB当量）；读取门前置；**但面积≠熵**（zlib 反测）
4. 文件货币化：应用黑盒 + 网关结算 + 面值卡防篡改；假 PNG 事件
5. 外部免疫：同层监控=没有监控 → 另一台机器上的免疫；四个坑（ps 截断/mksh 无 /dev/tcp/误杀自己/变量名）
6. 结论：这套东西在真机上每天跑；MIT 开源；欢迎戳
> 结尾钩子：`git clone` 后 3 条命令可复现词元寻址与面积报告。

## 3. 小红书 / 即刻 短帖版

**标题**：把 10 万个文件变成智能体的"脑"：零 token 也能一句话找到文件

正文（短句，配 3 图）：
```
我不给智能体装向量数据库。
我把它所有文件名切成词元，建了一个"地址网络"。
问它"五公理 体检"，它直接指出那个 .py 文件——不花一分钱 token。

然后是算力当量：
7.28GB 的盘，按"编码系数×容量"算，面积 314GB当量（43倍）。
超过阈值的文件强制流式读——大文件再也不会把内存炸了。

再然后，应用变黑盒，文件变货币：
应用只登记"吃什么/拉什么"，网关拦截产物、打面值、入库、记账、验真。
有一次 URL 说自己是 PNG，实际返回 HTML——当场被抓包。

最狠的是免疫：会杀自己的脚本和细胞同层，等于没有监控。
所以我们把免疫放到另一台常开的机器上，无线 adb 探心跳，宕机就电醒。

代码 MIT，报告是真的数字。想看的评论区扣 1。
```
