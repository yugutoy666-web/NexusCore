# PHILOSOPHY · 组装大于单体（Assembly > Monolith）

> 不要尝试训练一个 100 亿参数的超级大脑，去组装 3 个不同物理介质的计算节点。
> 大模型是廉价的脑子，而跨设备组装、因果图论和异层免疫，才是智能体真正的身体。

## 一、核心命题
```
命题 1（廉价算力）：模型能力正在商品化 —— 任何人都能买到"够用的脑子"。
命题 2（昂贵身体）：一个能活、能看、能动手、能自愈、能跨设备协同的身体，
                    无法用钱买到，只能被组装出来。
命题 3（涌现）：N 个异构节点按图论连接 + 异层免疫 + 文件货币结算，
               产生的可用智能 > 单个节点能力之和。
结论：壁垒不在参数，在组装。
```

## 二、跨物理介质组装（异构矩阵）
```
介质         角色                              能力边界
Android 手机 传感器层/嘴耳/触觉/语义流(a11y)    可看可听可说可点，无 root 不能内核级
Linux 服务器 常驻脑/免疫/统一根/镜像/网关       无人值守、systemd 稳定、跨设备挂载
Windows+GPU  闲置算力/桌面自动化/渲染           GUI 会话限制、需交互会话
人类数据盘   存档/素材/人的根                   只读管理、按写入规范
```
**同一套内核（快脑/慢脑/网关/免疫）在三类 OS 上以不同角色运行**，通过端口/HTTP/adb/ssh 互相调度——像积木。

## 四、"智联网操作系统"的判据（可检验）
```
1 任一节点宕机，其余节点可在 60s 内接管其角色（已验证：戴尔免疫救手机）
2 同一功能可迁移到不同介质（待验证：快脑搬到戴尔运行，红米只做传感器）
3 应用只暴露输入/输出规则，内部依赖不透明（App_Model 宏节点）
4 跨介质文件读写像本地（统一根 FUSE）
5 感知有同意机制与指示器（产品层隐私红线）
```

## 五、诚实的边界
```
· 组装能力受限于每个介质的开放接口（无 root 的 Android、受限的 Windows shell）
· "涌现"需要连接质量：一台常开节点 + 稳定网络是下限
· 这套架构替代不了基础模型的能力上限；它只让"够用的模型"变成"能干活的身体"
```
