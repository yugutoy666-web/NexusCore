# REPORT · File-Currency Settlement（文件货币结算实录）

> 应用 = 黑盒宏节点（只登记 inputs/outputs），文件 = 货币，交互 = 结算。
> 工具：`src/gateway.py`（本仓库）· 数据脱敏（URL 用公共示例站）

## 一、面值模型

```
面值卡 = { 字节, 系数, 面积当量(=系数×字节), 熵密度(=zlib压缩率), sha256[:16], 输入, 应用, 时间 }
货币入库 → 面值卡旁挂 → 账本追加 → 验真(重算 sha+面积 对卡) → 面值不可篡改
```

## 二、三笔真实结算

| # | 黑盒应用 | 输入货币 | 输出货币 | 字节 | 系数 | 面值(字节当量) | 熵密度 |
|---|---|---|---|---|---|---|---|
| 1 | GUI 浏览器（headless 截图） | URL | .png 截图 | 6,772 | 20 | 135,440 | 0.371 |
| 2 | 下载器（curl） | URL | .html | 577 | 3 | 1,731 | 0.676 |
| 3 | 下载器（curl） | URL | .html（伪装 PNG） | 15,770 | 3 | 47,310 | 0.981 |

验真：`重算 sha256 + 面积 == 面值卡` → ✅ 未篡改。

## 三、「假 PNG」拦截实录（本报告最有价值的一条）

```
输入: https://…/image.png（URL 声称 PNG）
输出: 15,770 字节，实际内容为 HTML（错误页/重定向页）
网关行为: 按 URL 扩展名 → 误定价为 .png 系数 20（应为 .html 系数 3）
          且该 HTML 熵密度 0.981（高熵）进一步暴露"这不是图片"
教训: 币种必须按内容（魔数）识别，不能信 URL 扩展名 → v0.2 魔数嗅探
```

## 四、撞出来的工程坑（全部已修）

1. **GUI 应用不能在没有交互桌面的会话里跑**（浏览器 headless 会挂起）→ 应用模型需登记 `session` 需求，GUI 类标记 `Blocked`。
2. **SSH → Windows cmd 会吃掉命令里的引号** → 网关改「零引号命令」（路径无空格裸写）。
3. **Windows 远端文件名必须 ASCII**（中文经 GBK 必乱）→ 远端用 `gw@<ts>.<ext>`，本地再转展示名。
4. **URL 扩展名不可信**（假 PNG）→ 内容嗅探（规划中）。
